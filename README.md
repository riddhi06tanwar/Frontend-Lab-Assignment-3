# 🚀 Frontend Lab Assignment 3

A collection of interactive web applications built using **HTML, CSS, and JavaScript** as part of a frontend development lab assignment.

## 📌 Projects Included

### 1. 🧮 BMI Calculator
- Calculates Body Mass Index using height and weight.
- Displays the BMI value and weight category.

### 2. 📝 Signup Form
- Includes name, email, and password fields.
- Validates user input and checks password confirmation.
- Displays success and error messages.

### 3. 🎨 Theme Changer
- Switches between light and dark themes.
- Saves the selected theme using Local Storage.

### 4. 🕒 Digital Clock
- Displays the current time and date.
- Updates automatically every second.

### 5. ✅ To-Do List
- Add new tasks.
- Mark tasks as completed.
- Delete individual tasks.
- Clear all completed tasks.
- Save tasks in browser Local Storage.

## 🛠️ Technologies Used

- **HTML5** — Webpage structure
- **CSS3** — Styling and responsive design
- **JavaScript (ES6+)** — Application logic and interactivity
- **Local Storage** — Saving theme preferences and tasks
